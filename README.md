StockStack-Full-Stack-Investment-Management-Platform

## 📌 Project Overview

This project is a full-stack web application inspired by Zerodha, designed to replicate the interface and key features of an online stock trading platform. It includes a landing page and a trading dashboard for viewing holdings, positions, stock information, and investment-related data.

The project demonstrates full-stack development by integrating React.js, Node.js, Express.js, and MongoDB.

## ✨ Features

- **Interactive Landing Page:** Displays information about trading products, pricing, and services.
- **Trading Dashboard:** Provides an interface to explore stock-related information.
- **Stock Watchlist:** Displays stock information and price visualizations.
- **Holdings Management:** Displays holdings, quantities, average prices, current values, and profit or loss.
- **Positions Tracking:** Shows position details and profit or loss.
- **Buy Orders:** Provides an interface to enter stock quantities and prices and submit orders.
- **Funds Overview:** Displays funds and margin information.
- **Data Visualization:** Uses charts to present stock-related data.
